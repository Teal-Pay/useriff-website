# Platform partner logos

Retrieved from the platforms’ official brand resources on November 19, 2026.
These are brand wordmarks, not certification badges. The homepage applies the
same grayscale filter and opacity as the existing customer logo rows.

- Google: current Google brand breadcrumb artwork from [Partner Marketing Hub](https://partnermarketinghub.withgoogle.com/brands/google/overview/).
- TikTok: `TikTok-logo-RGB-Horizontal-black-simplified.png` from the [official developer logo pack](https://developers.tiktok.com/docs/en/getting-started-design-guidelines).
- YouTube: `Digital/02 Almost Black/yt_logo_almostblack_digital.png` from the current [official logo pack](https://brand.youtube/youtube-logo).

Transparent canvas padding is trimmed for consistent optical sizing. TikTok and
YouTube PNGs are downsampled to 600px wide for web use. Logo artwork is preserved.
